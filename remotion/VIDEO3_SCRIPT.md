# Haefit — Cinematic Promo Video Script

**Video**: CinematicPromo (Video3.tsx)  
**Duration**: 60 seconds | 1080×1920 portrait | 30 fps  
**Target**: Gym owners, fitness studio managers, personal trainers (India)  
**Tone**: Professional, empathetic, modern — "Apple launch meets gym hustle"

**Style**: Ambient electronic with a building energy arc  
**Recommended**: Cinematic lo-fi beat → builds to uplifting synth drop at Scene 3 → steady pulse through features → emotional piano at Scene 9 → triumphant resolve at CTA  
**BPM**: 90–110  
**References**: Think "Epidemic Sound — Inspiring Technology" or "Artlist — Corporate Innovation"

## Rendering

```bash
# Preview in Remotion Studio
npx remotion studio

# Render to MP4 (H.264)
npx remotion render CinematicPromo out/haefit-promo.mp4

# Render at higher quality
npx remotion render CinematicPromo out/haefit-promo.mp4 --codec h264 --crf 18

# Render with transparency (for overlay editing)
npx remotion render CinematicPromo out/haefit-promo.webm --codec vp8
```
